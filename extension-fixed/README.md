# ClaudePacer — Chrome Extension

> Stop driving Claude without a speedometer or gas gauge.

A beautiful, one-click Chrome extension that shows your live Claude burn rate
and weekly budget right in your browser toolbar — no setup, no accounts, no
proxies. Just install and go.

---

## Install in 60 seconds (Developer Mode)

Until ClaudePacer is on the Chrome Web Store, install it manually:

1. **Download** — click the green `Code` button on this page → `Download ZIP`
   and unzip it somewhere easy to find (like your Desktop).

2. **Open Chrome extensions** — type `chrome://extensions` in your address bar
   and press Enter.

3. **Enable Developer Mode** — flip the toggle in the top-right corner.

4. **Load the extension** — click `Load unpacked`, then navigate to the
   `extension` folder inside the unzipped download. Select it and click
   `Open`.

5. **Done!** The ClaudePacer icon appears in your toolbar.
   Pin it by clicking the puzzle-piece icon → pin ClaudePacer.

---

## How it works

1. You use Claude normally at **claude.ai**
2. ClaudePacer quietly watches the page in the background
3. It counts tokens from every response as they stream in
4. Click the toolbar icon any time to see your live dashboard

**Nothing is sent anywhere.** All data stays on your device in Chrome's
local storage. No account needed for the free tier.

## The dashboard

| What you see | What it means |
|---|---|
| **Speedometer** | Your current burn rate in tokens/min. Green = relaxed, amber = active, red = floored. |
| **Gas gauge** | % of your weekly budget used + projected days remaining at this pace. |
| **Session / Week / Messages** | Quick stats at a glance. |
| **Burn rate badge** | Live % shown on the extension icon so you never have to click to check. |

- Reset all usage data
