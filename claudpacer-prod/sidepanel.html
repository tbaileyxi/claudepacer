Set up the Claude Code bridge
3 quick steps — takes about 2 minutes
1
Open Terminal
Press Cmd ⌘ + Space → type Terminal → hit Enter
2
Check for Node.js
In Terminal, paste this and hit Enter:
node --version
See v18 or higher? Great, skip to step 3.
See "command not found"? Download Node.js (free, takes 1 min).
3
Install the bridge (runs automatically from now on)
In Finder, go to Documents → ClaudePacer → claude-bridge and double-click:
install-bridge.command
That's it — no Terminal window needed. The bridge starts automatically every time you log in.
The ⌨️ Claude Code chip will appear in the panel header once the bridge connects.
