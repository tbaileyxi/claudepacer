ClaudePacer Privacy Policy

Protecting your privacy while you optimize your Claude usage

Overview

ClaudePacer is a Chrome extension that helps you monitor and optimize your Claude.ai token usage. We are committed to protecting your privacy and being transparent about the data we collect and how we use it.

Important: ClaudePacer processes all data locally on your device. We do not collect, store, or transmit your Claude conversations or personal information to our servers.

Data We Collect

Token Usage Data

To provide the speedometer and gas gauge functionality, we collect:

  • Token counts from your Claude.ai requests and responses
  • Timing information for burn rate calculations
  • Weekly and session usage totals
  • Usage limits and reset times (scraped from your Claude settings)

Local Storage

All data is stored locally in your browser's chrome.storage.local:

  • Usage statistics and calculations
  • Settings and preferences
  • Pro license status (if purchased)
  • Temporary email for waitlist (if provided)

Data We Don't Collect

  • Conversation content: We never access or store your actual Claude conversations
  • Personal information: No names, emails, or identifiers (except waitlist email you voluntarily provide)
  • API keys: We have no access to your Claude API keys
  • Browsing history: We only monitor claude.ai for token interception

How Data Is Processed

Token Interception

The extension intercepts network requests to claude.ai to extract token counts from:

  • Request bodies (for input token estimation)
  • Streaming responses (for output token counting)
  • Usage page data (for calibration)

Desktop Bridge (Optional)

If you use Claude Code desktop app, you can optionally run a local bridge that:

  • Runs on localhost (127.0.0.1) only
  • Reads local Claude log files
  • Sends token deltas to the extension
  • No data leaves your computer

Payment Processing

For Pro upgrades:

  • Payments are processed through Square's secure platform
  • We receive only payment confirmation (no card details)
  • Pro status is stored locally in your browser
  • No payment information is stored by the extension

Data Sharing

We do not share, sell, or transfer your data to third parties, except:

  • Payment processors for transaction processing (Square)
  • As required by law or legal process

Data Security

  • All data is encrypted at rest in browser storage
  • No data is transmitted to external servers
  • Payment processing uses industry-standard security
  • Regular security updates and reviews

Your Rights

You have the right to:

  • Access all locally stored data
  • Delete all extension data
  • Disable the extension at any time
  • Request data deletion (though no data is stored on our servers)

Changes to This Policy

We may update this privacy policy occasionally. Changes will be posted here and, if significant, communicated through the extension.

Chrome Web Store Requirements

This privacy policy is maintained in compliance with Chrome Web Store developer policies.
